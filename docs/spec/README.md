# Техническое задание

Сайт строился по техническому заданию заказчика, версия 1.1 от 24.09.2026. Сам файл задания в репозиторий не включён: ТЗ передаётся заказчиком отдельно. В коде и в остальных документах на него ссылаются как «ТЗ §NN».

Ниже — что в какой части документации отвечает разделам задания, чтобы читать её можно было и без самого файла.

| Раздел ТЗ | О чём | Где в документации |
|---|---|---|
| 04–05 | Карта сайта, главная по блокам | `ARCHITECTURE.md`, «Маршруты и раскладки» |
| 06 | 3D-модель тела | `ARCHITECTURE.md`, «3D-блок» |
| 07 | Сценарий записи | `BACKEND-CONTRACT.md`, раздел 3 |
| 08 | Интеграция с Altegio, маршруты сервера, типы | `BACKEND-CONTRACT.md` |
| 09 | Личный кабинет | `BACKEND-CONTRACT.md`, раздел 4 |
| 11–12 | Дизайн-система, экраны и языки | `ARCHITECTURE.md`, «Стили и токены», «Тексты и языки» |
| 13 | Технические требования | `ARCHITECTURE.md`, `TESTING.md` |
| 14 | SEO и аналитика | `ANALYTICS-SEO.md` |
| 15 | Управление содержимым (CMS) | не делалось |

## Что из ТЗ сделано, а что нет

Сделан первый этап: интерфейс всех страниц на демо-данных. Серверная часть ТЗ не делалась.

| Требование ТЗ | Состояние |
|---|---|
| Страницы сайта, запись в 7 шагов, 3D-модель, кабинет, два языка | Сделано как интерфейс |
| Сервер сайта (BFF) с маршрутами `/api/booking/*`, `/api/account/*` (§08) | Не делалось. На месте маршрутов заглушки в браузере |
| Данные из Altegio: услуги, цены, расписание, записи (§08) | Не делалось. Демо-каталог в `src/lib/api/` |
| Вход по SMS, сессия, запись по ссылке (§09) | Не делалось. Экраны есть, проверки нет |
| Капча Turnstile, ограничение частоты, резервная очередь с уведомлением в Telegram (§07–08) | Не делалось. Поведение изображает заглушка |
| CMS для текстов, статей, правил подбора услуги (§15) | Не делалось. Тексты в `messages/*.json` |
| Мониторинг ошибок (§13) | Не делалось |
| Аналитика (§14) | События и режим согласия в коде есть; контейнер GTM не подключён |

## Решения, которые уточняют ТЗ

Каждое записано в коде, путь рядом.

| Решение | Где видно |
|---|---|
| Код по SMS на шаге 6 записи выключен (решение заказчика от 06.11.2026); включается переменной сборки | `src/lib/config.ts` |
| На сайте нет слов «лечение», «физиотерапия», «диагностика» и их английских пар; на лендингах и в рекламе дополнительно нет «реабилитация», «ЛФК», «мануальная», «кинезиотерапия», «приватный» | `e2e/fixtures/lexicon-denylist.json`, проверки в `e2e/seo.spec.ts` и `e2e/lp.spec.ts` |
| Цвета и шрифт по ТЗ §11 с поправками на контраст AA для мелкого акцентного текста | `src/styles/tokens.css` |
| Добавлена зона «передняя поверхность голени» (решение заказчика от 06.11.2026) | `src/lib/body3d/zones-meta.json` |
| На главной при невозможности показать 3D остаётся постер модели, 2D-схема показывается только в записи | `src/components/body3d/Body3DSlot.tsx` |
| В аналитику не уходят зоны, заметки, названия услуг и контакты; идентификаторы услуги и специалиста — только числа | `src/lib/analytics/track.ts` |
| UTM-метки хранятся в cookie только с согласия посетителя | `src/lib/analytics/utm.ts` |
| Сайт выложен закрытым от поисковиков до решения о запуске | `src/app/robots.ts`, `src/lib/seo.ts` |

Рабочие заметки команды (распределение задач, внутренние проверки) в репозиторий не включены.
