# Документ для отдела маркетинга

`marketing-guide.html` — описание сайта и рекламных лендингов для отдела маркетинга: что измеряется, что можно и чего нельзя включать, чек-лист перед запуском рекламы.

**Как читать.** Это один самодостаточный HTML-файл: без скриптов и без внешних файлов, всё оформление внутри. GitHub показывает его как исходный код, а не как страницу. Чтобы прочитать, скачайте файл (кнопка «Download raw file» на его странице в GitHub или копия из репозитория на диске) и откройте в браузере. Подходит и для телефона.

**Для какой версии сайта.** Документ написан для выпуска RC-10, по коду коммита `9c029a2`. Если сайт изменился, сверяйте с `docs/CHANGELOG.md`.

**Что важно знать до чтения.** Контейнер Google Tag Manager с тегами Meta и Google Ads можно подключать только к выпуску RC-10 или новее: в RC-9 номер услуги попадал в адрес страницы записи. Какой выпуск стоит на живом сайте — в `docs/CHANGELOG.md`.

Техническая сторона тех же тем — в `docs/ANALYTICS-SEO.md`.
