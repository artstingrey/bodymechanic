# 7.1. Запись со страницы услуги — передача

Выполнена только 7.1. Hero детальной страницы использует существующий `BookingLink` с `service: s.id` из разрешённой услуги. Точки входа: `/{locale}/services/{slug}/` → `/{locale}/booking/` → `/{locale}/booking/?step=2`. Текст, классы и расположение CTA сохранены. Демо-маршруты и таблица подтверждённых соответствий не менялись.

На production-сборке с синтетическим Altegio в Chrome проверены `/ru/services/sports/` и `/en/services/sports/`: первый шаг открылся с 3D-моделью, на втором выбран `13982355`, в URL и `href` нет ID. Новый выбор заменяет другую услугу из действующего черновика, сбрасывает специалиста, дату и время визита, сохраняет зоны и контакты. При исчезновении услуги из каталога выбор очищается и можно выбрать другую услугу. Открытие в новой вкладке и переход по скопированному адресу работают без предвыбора.

Прошли production-сборка без CRM, `lint`, `tsc --noEmit`, `i18n`, `test:booking-services`, `test:service-details` и `test:service-staff`. Отдельно подтверждена отрисовка 3D в Chrome с WebGL в обеих локалях. GET-сверку филиала не проводили: в доступном окружении нет настроек Altegio, файлы `.env` не открывались.

Часть 7.2 не начата. Для продолжения нужна отдельная команда.
