## Черновик, прямые ссылки и язык

- [Store маркеров](../../src/lib/body3d/store.ts) восстанавливает модель, маркеры с координатами и нормалями, интенсивность и заметки из `bm.bookingDraft`. [useBookingSelection](../../src/components/booking/useBookingSelection.ts) восстанавливает услугу, специалиста, день, окно, предпочтения ссылки и контакты из `bm.bookingSteps`. [Снимок результата](../../src/lib/booking/result.ts) хранится отдельно в `bm.bookingResult`. Все три ключа живут в `sessionStorage` вкладки. При чтении записи старше 24 часов удаляются по их собственным меткам. Черновики без метки допускаются до следующего сохранения.
- На шаге 1 «Продолжить / Начать заново» появляется при восстановленных маркерах, общей заметке или сохранённой услуге. «Продолжить» с выбранной услугой переходит к первому незаполненному шагу, без услуги оставляет на шаге 1. Back/Forward меняют шаг, читается текущий черновик вкладки. `?step=2…7` скрывает первый шаг до гидратации. Строгая проверка пройденных шагов отсутствует, специальное перенаправление действует для шага 7 без результата.
- [BookingLink](../../src/components/booking/BookingLink.tsx) передаёт пресет в `bm.bookingPreset` и память документа при обычном клике в той же вкладке. В `href` остаётся `/booking/` с необязательным `step`. При копировании, открытии в новой вкладке и клике с модификатором пресет не передаётся. [Внешние ссылки](../../src/lib/booking/preset.ts) принимают `service`, `staff`, `date`, `time`. Параметры переносятся в пресет и синхронно удаляются из URL до считывания аналитикой, `step`, UTM и hash сохраняются при очистке. Пресет одноразовый, для передачи между документами действует минутная свежесть до привязки к новому документу.
- Источники демо-ID — CTA демостраниц услуг, страницы демоспециалистов и их ближайшие окна, кнопка «Записаться снова» из демокабинета. Реальные детальные страницы пока скрывают CTA записи. В URL для внешнего входа, включая формат `Offer.url` в JSON-LD, текущий хук принимает `service` только при совпадении с массивом демоуслуг. Положительный `staff` сохраняется без проверки списка. Пресет услуги при её смене сбрасывает дату и окно, пресет даты заменяет их предпочтением.
- При пресете `staff+date+time` ссылка ближайшего окна открывает шаг 2. После выбора услуги переход идёт сразу на шаг 4, если есть все три значения. Дата подставляется только если доступна, окно — только если есть точное `HH:mm`. Иначе появляется подсказка о несовместимом окне. Ссылка с одной услугой без `step` открывает шаг 1 с уже выбранной услугой. `LangSwitch` сохраняет текущий шаг, query, hash и флаг входа с собственной услугой. Значения остаются в хранилище вкладки, названия списков вычисляются в новой локали. Шаг 7 сохраняет название услуги из снимка результата.

## Правила подбора

[ZONE_RULES](../../src/lib/api/mock-data.ts#L55) задаёт списки демоуслуг по базовой зоне. [recommendServices](../../src/lib/api/index.ts#L159) снимает суффикс `_l` / `_r` и добавляет по одному баллу каждой услуге из правила за каждый маркер. Обе стороны одной зоны дают два балла. Повторные маркеры также учитываются отдельно, заметки и интенсивность в баллах не участвуют. При равенстве стабильная сортировка сохраняет порядок первого попадания ID в `Map`, заданный порядком маркеров и элементов правила. Например, `neck_collar` выводит `sports` перед `manual`, `thoracic_spine` меняет их местами.

Рекомендованные услуги поднимаются вверх по рангу, остаток остаётся в порядке каталога. Плашка «Рекомендуем» ставится только при `s.id === recommended[0]`. Без маркеров, в том числе при одной общей заметке, и без совпавших правил остаётся обычный список без плашки. Если первый ID отсутствует в каталоге, остальные совпавшие услуги сохраняют порядок, плашка исчезает. Для 6.2 сначала ограничить рекомендации опубликованными ID, затем ставить плашку у первой оставшейся услуги. [PR-004](../POST-RELEASE-IMPROVEMENTS.md#pr-004-доработать-zone-rules) остаётся отдельной задачей.

## Проверки

- **Филиал.** Только GET к уже запущенному каталогу, включая детали подтверждённых и спорных карточек. Запись в Altegio не создавалась. Файлы `.env` и архив не открывались.
- **Браузер.** 17 целевых Playwright-проверок прошли на имеющейся локальной production-сборке с HTTP-доступом только на чтение. Проверены семь шагов демосценария, Back/Forward и F5, прямые ссылки, CTA демоуслуги, смена языка, конфликт окна, `queued`, восстановление результата, срок и сброс черновика, перенос 3D-host с главной, переход 3D ↔ 2D и отсутствие WebGL. Первый прогон по уже запущенному серверу для сверки каталога дал таймауты UI. Повтор на production-сборке прошёл.
- **Подбор.** Девять проверок функций и наличия ID покрыли отсутствие маркеров, неизвестную зону, две стороны, порядок при равенстве и отсутствие лидера в списке услуг. Дополнительный проход в Chrome на RU и EN подтвердил отсутствие плашки без маркеров, плашку классического массажа для груди, принятие демо-ID и игнорирование реального ID в пресете, очистку URL с сохранением UTM и hash.
